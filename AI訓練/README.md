訓練迴圈骨架（純介面示意；RL 套件自選，環境本身零相依）：

```python
from incense_env import IncenseEnv, DualAscent

env = IncenseEnv(randomize=True)          # 域隨機化＝第 19 週 sim-to-real 對策
dual = DualAscent(["noise", "h_vis"], alpha=0.5)
for episode in range(n_episodes):
    obs, done = env.reset(seed=episode), False
    g_sum = {"noise": 0.0, "h_vis": 0.0}; steps = 0
    while not done:
        a = policy(env.obs_vector(obs))          # 只准看 obs（感測值）
        obs, r, done, info = env.step(a)
        loss = -r + dual.penalty(info["g"])      # 硬約束走對偶罰項
        for k in g_sum: g_sum[k] += info["g"][k]
        steps += 1
        # ...存 (obs, a, -loss) 進 replay buffer...
    dual.update({k: v / steps for k, v in g_sum.items()})   # λ ← max(0, λ+αḡ)
```

## 風扇規格（2026-08-16 使用者指定）

訓練調控風扇＝**建準 SUNON 4020**（40×40×20 mm、DC12V、PWM、磁浮軸承），
**安裝於罩口**。未指定型號檔位——`sim_config.py` 以家族典型中值建模
（工作點風量 12 m³/h、全速約 30 dBA、約 1 W、最低啟轉 duty ≈10%），
全部標 EST，拿到 datasheet 與 P–Q 實測（§5.2 實驗 1）後回填。
4 線 PWM 直控順帶解掉兩個舊待辦：490 Hz 嘯叫（PWM 走控制線非電源線）
與轉速回授（FG/tach 線）。

**此規格帶來的政權變更**（模擬已反映）：磁浮扇全速 ~30 dBA « 45 dBA 上限、
最大面風速 0.13 m/s < 單支煙羽速度 0.40 m/s → **噪音與文化兩條硬約束
天然滿足、不再是主動約束**；「有香就全速」成為合法邊界解，
學習的價值轉移到**時間軸排程**：沒香該關（能耗/濾材/平滑）、
香要來該先開（初一十五與 CO2 前饋的預測性啟動）。

### ★設計張力（誠實記錄，非本目錄能解，需人決策）★

1. **風量缺口**：4020 工作點約 6–22 m³/h，D26 規格為 43.3 m³/h——
   模擬顯示單顆全速常開僅將超標時率 54.6%→48.7%（模擬值）。
   選項：接受較低 η／多顆並聯／保留 5015 鼓風機於濾箱、4020 只做罩口助抽。
2. **靜壓不足**：濾鏈初始壓損約 165 Pa（紗網 5＋HEPA 120＋活性碳 40），
   4020 軸流靜壓僅數十 Pa——**單靠 4020 推不動濾鏈**，若它是唯一風扇，
   過濾段需另行驅動或重新設計。
3. **D13 被推翻**：原決策「風扇置於過濾鏈之後（扇葉不吃香灰油煙）」；
   罩口安裝＝扇葉直接暴露於煙流與火星。磁浮軸承耐汙較佳但扇葉積垢
   仍在，且**金屬紗網（火星前濾）應前移到風扇之前**——FILTER_CHAIN
   順序紅線不動，但「紗網相對風扇的位置」需要重新拍板。
4. **面風速均勻性**：40 mm 扇盤對 180 mm 罩口，流場集中於中心——
   本模型的均勻面風速假設對此配置不確定度最大（§5.2 實驗 7 的量測項）。

## 設計要點（皆有日誌出處）

1. **損失函數＝第 15 週定義**：暴露線性（扣 C_bg、無閾值）＋超標二次；
   能耗 u³（風扇相似定律）；濾材 u（壽命∝總風量）；平滑 Δu²（變動噪音
   比穩定噪音更干擾）。
2. **文化與噪音是硬約束**（D11）：h_vis ≥ h_spec 與 SPL ≤ 45 不進權重，
   違反量走 `info["g"]`，由 `DualAscent` 處理——把它們改成固定權重
   ＝重犯日誌已否決的錯誤。
3. **策略只看感測值**：`obs` 含雜訊、5 s 更新、延遲與失聯；真值在 `info`
   只准診斷。近場濃度**沒有感測器**——跟實機一樣。
4. **安全聯鎖屬於環境**：CO2>1500→全速、超溫→停機（同韌體），策略蓋不過；
   訓練出的策略必須在聯鎖存在下仍表現好。
5. **域隨機化**（第 19 週）：η、排放因子（7–100 log-uniform）、ACH、C_bg、
   感測延遲，加上煙羽（db/dz、源徑）與橫流／側裙（SKIRT_ATTEN 下探 1.0
   ＝側裙完全失效的 B8 惡夢情境）。**策略不得依賴任一估計值的精確度。**
