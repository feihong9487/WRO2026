# 最重要的規則（違反等於整組作廢）

1. **只能使用本指令包提供的數字與事實，一個都不准自己編。**
   每個數字後面標了證據等級，呈現時必須遵守：
   - ［實測］［文獻實測］［官方統計］：可直接陳述。
   - ［設計目標］：必須帶「設計目標」「將實測檢定」字樣，不可寫成已達成的成效。
   - ［模擬］：必須標示為模擬資料。
   - ［假設推估］［概念估算］：必須標示為推估／估算。
2. **絕對不可出現**：過濾效率百分比、PM2.5 改善百分比等成效數字（全部尚未實測）；
   「理香機構」「磁力矩陣」「插孔板」「電磁鐵」（此機構已從設計移除，只能以
   「曾開發後主動移除」的迭代故事形式出現，位置在第二張海報）；乾冰（展示禁用）。
3. 團隊是高中生，語氣自信但誠實，不浮誇。「誠實」是這個團隊的招牌。
4. 標題寫成結論句，不寫類別標籤（寫「十年成本只要金爐的 1/8」，不寫「成本分析」）。

# 事實庫（宣稱清單）

## 問題面
- 台大團隊於龍山寺殿內實測 PM2.5 一度達 1,360 μg/m³，約為戶外平均 50 倍（公視 2015）［文獻實測］
- 台灣廟宇殿內 PM2.5 平均 97.0±65.4 μg/m³（AAQR 同儕審查研究 2022）［文獻實測］
- 全球佛教＋道教＋印度教焚香信仰人口約 22 億［文獻統計］
- 環保署每年收到宮廟空污陳情超過 3,000 件［官方統計］
- 全台年燒約 3 千噸線香＋24 萬噸金紙 ≈ 2 萬輛汽車年排氣量（環保署 2016 統計轉引）［官方統計］
- 2017 年「減香」誤傳「滅香」，數萬人上凱道抗爭［歷史事件］
- 長期每日焚香與呼吸道鱗癌相關，風險比 1.8（95% CI 1.2–2.6，新加坡 61,320 人世代研究，Friborg 2008）［文獻實測］
- 台灣登記寺廟 12,279 座（內政部 2019），其中傳統宮廟約 9 千餘座［官方統計］

## 既有方案的缺口
- 封爐/心香：行天宮 2014 撤爐後殿內 PM2.5 降至 15.2 μg/m³，但儀式被犧牲［文獻實測＋定性］
- 碳中和金爐：北港武德宮方案約 500 萬元，中小廟宇無法複製［新聞報導］
- 市售清淨機：常溫全室設計，管不到高溫爐口點源［定性］
- IoT 監測服務：只量測、不治理，沒有致動器［定性］

## 我們的方案（現行設計，2026-08-16 定版）
- 兩板架構：MATRIX Mini R4（感測＋安全＋致動）＋ Raspberry Pi 5（決策＋上雲）［實作］
- 感測：SCD41 CO₂、SHT31 溫濕、MAX6675 K 型熱電偶爐溫、DS18B20［實作］
- 決策：有限狀態機 S0 待機／S1 常態／S2 高峰／S3 異常；門檻相對背景基線
  （進高峰＝基線+300ppm、遲滯退場＝基線+200、前饋斜率門檻 θ_ff=120 ppm/min；
  風扇 duty S0/S1/S2＝0/70/220）［實作，門檻與實機韌體同步］
- 核心智慧＝CO₂ 前饋削峰：CO₂ 由人群呼出、先於插香高峰數分鐘上升，是人流先行
  指標——人潮還沒插香，抽排已預先加速［設計原理，前饋方法為方法專利主張核心］
- 機構：漏斗大口集煙罩（罩頂外擴 180mm、插香不必對準；下段直筒接風扇法蘭）＋
  三段過濾鏈（金屬紗網擋火星 → HEPA → 活性碳，順序即安全）＋ 變頻抽排［設計定版］
- 安全五級階梯：雲端斷＝本地續跑補傳／Pi 失效＝控制器 5 秒逾時接手本地 FSM／
  感測失效＝回報 -99.9 故障值＋安全態優先／超溫或熱電偶失效＝就地聯鎖直接拉低
  PWM 腳、風扇歸零／全系統斷電＝香爐回復傳統使用（故障安全）［實作］
- 悶燒偵測：CO/CO₂ 比＋爐溫特徵 → 60 秒內強化抽排＋告警［設計目標，將實測檢定］

## 海報 1／3「問題篇」——標題：我們讓香繼續燒，但煙不再害人。
- 頂部：主視覺（香爐＋裊煙意象）＋「智慧香爐」大字＋標語「香火不滅・空氣常青」
- 三個巨型數字：50 倍（殿內 PM2.5 vs 戶外）／22 億人（焚香信仰人口）／
  3,000+（年宮廟空污陳情）
- 「為什麼過去都失敗」三行對比：封爐減香→儀式被犧牲／碳中和金爐 500 萬→
  中小廟買不起／清淨機・IoT→治標不治本
- 第一性原理框：空污濃度＝產生速率−移除速率；產生端是信仰動不得→只放大移除端
- 底部宣言（大字）：「不禁香・不封爐——把治理裝進香爐，而不是把禁令加在信眾身上」

## 海報 2／3「系統篇」——標題：讓香爐自己學會呼吸
- 產品/機構區：漏斗大口集煙罩＋三段過濾鏈（紗網→HEPA→活性碳，順序即安全）＋
  變頻抽排（留一個放實機照片/CAD 圖的位置）
- 三層閉環圖：感測（爐口/呼吸高度/進出風口三點）→ 決策（FSM＋CO₂ 前饋）→
  機構（抽排過濾）；決策全紀錄可重演
- 決策核心：FSM 四態圖＋門檻數字（基線+300 進高峰、+200 遲滯退場、θ=120 ppm/min）
- 五級故障安全階梯（表列，強調「每一層都往安全的方向倒」）
- 迭代故事框：敢刪的理香機構＋漏斗改版
